# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent to people. Harassment, personal attacks, and demeaning
comments are not acceptable, and participation can be withdrawn over them.

Report concerns by opening a private security advisory on this repository, or
by contacting the maintainer directly.
