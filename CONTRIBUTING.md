# Contributing to hermeneutica

Issues and pull requests are welcome.

## Setup

```bash
git clone https://github.com/Lumi-node/hermeneutica.git
cd hermeneutica
# see the README for the toolchain
```

## Pull requests

- Keep the change focused; one concern per PR.
- Add a test if you are fixing a bug — a test that fails before your change and
  passes after is the fastest way to get it merged.
- Run whatever the CI workflow runs before pushing.

## Reporting a bug

Include what you ran, what you expected, and what happened. A reproduction is
worth more than a description.
